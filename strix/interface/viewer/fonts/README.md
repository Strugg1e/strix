# Embedded report font

The `NotoSansSC-Regular.ttf` and `NotoSansSC-Bold.ttf` files are static
instances of Google's **Noto Sans SC** variable font. They were generated from
the Google Fonts source at:

<https://github.com/google/fonts/tree/main/ofl/notosanssc>

The source variable font is `NotoSansSC[wght].ttf` (blob SHA
`fb0637bafbcd804fe32152370a1225990745b4bc`). The regular and bold instances
pin the `wght` axis to 400 and 700 respectively using `fontTools.varLib`.

Generated file checksums (SHA-256):

- `NotoSansSC-Regular.ttf`: `9c61d45e8773f4b7eed32401fcb181efc4e77e69ca1d81c3bb7d7db6ddbb8fb0`
- `NotoSansSC-Bold.ttf`: `9d05a3517eec19cf9406b4d1870ece613c767628c33bf5af2ce48dfd43c38468`
